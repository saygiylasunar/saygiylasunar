# Ersen Filiz · `saygiylasunar`

**Computer Engineer · Front-end & UI Systems · Graphic Design**

I build practical software where **engineering, interface design, and visual systems** meet.

## About

I’m a computer engineer focused on turning complex ideas into clear, usable tools. I enjoy working across the boundary between software and design: shaping the architecture, building the interface, and refining how the final product feels to use.

My work tends to revolve around **local-first tools, creative software, compact interfaces, data-oriented workflows, and experimental utilities**. I prefer systems that stay understandable as they grow — simple where they can be, explicit where they need to be.

## Current focus

- Local-first desktop and AI tooling
- Fast, compact, resource-aware interfaces
- Personal knowledge and workflow systems
- Programmatic typography and visual systems
- Small tools that solve one problem well

## Selected projects

### [ReversenUI](https://github.com/saygiylasunar/reversenui)
Local-first AI engineering workbench for inspecting generative-image artifacts, composing model-aware prompts, processing outputs, and hosting local AI tools inside a desktop workspace.

### [EzgiWave](https://github.com/saygiylasunar/EzgiWave)
A compact multi-track audio companion for waveform visualization and per-track control, designed as a lightweight creative-tool interface.

### [Saygıyla Sunar Font](https://github.com/saygiylasunar/saygiylasunarfont)
An experimental typeface project exploring programmatic geometry, reusable glyph motifs, and a consistent monospaced system.

### [BellekPad](https://github.com/saygiylasunar/bellekpad)
An experimental personal workspace built around notes, projects, knowledge, and everyday operational memory.
